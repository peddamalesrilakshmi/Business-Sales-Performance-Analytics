# Business-Sales-Performance-Analytics

## 📌 Project Overview
This project analyses business sales data using Power BI to identify revenue trends, top-selling products, category-wise performance, and business insights.

## 🎯 Objective
- Analyse sales performance.
- Identify top-selling products.
- Compare sales across categories.
- Analyse profit trends.
- Create an interactive dashboard for business decision-making.

## 📊 Dataset
- Sample Superstore Dataset

## 🛠️ Tools Used
- Microsoft Power BI
- Microsoft Excel

## 📈 Dashboard Features
- Total Sales KPI
- Total Profit KPI
- Total Quantity KPI
- Average Sales KPI
- Sales Trend Analysis
- Sales by Category
- Top Selling Products
- Profit by Category
- Interactive Filters (Region, Category, Order Date)
